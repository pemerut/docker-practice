lesson 1.1

Container-to-container within a Pod	A logging sidecar contacts the Go server using localhost
Pod-to-Pod	Go API Pod contacts a PostgreSQL Pod
Pod-to-Service	Client contacts go-api using a stable DNS name
External-to-Service	A browser accesses your application from the internet

The most important foundational rule is that every ordinary Pod has its own IP address,
and Pods should be able to communicate over the cluster network without requiring
the application to know which physical node hosts the destination.
